# Kişisel Yapay Zeka Sekreteri (Telegram Bot)

Bu proje, **Halil Utku Çiçek** için 7/24 çalışan bir kişisel yapay zeka sekreteridir.

---

## 🎯 Ne Yapar?

1. **Gelenleri Karşılar:** Biri Telegram botunuza (`@halilutku_antigravity_bot`) yazdığında kibar ve profesyonel bir dille karşılar.
2. **Mesaj & Not Toplar:** Kişinin ne amaçla yazdığını, projesini, iletişim bilgilerini nazikçe öğrenir.
3. **Anında Admin Bildirimi:** Gelen her mesajı ve sekreterin verdiği yanıtı anında **Halil Utku'nun (Admin)** Telegram hesabına iletir.
4. **Sohbet Hafızası:** Kullanıcılarla olan konuşmaları hatırlar (`hafiza.json`).

---

## 🚀 Çalıştırma

### Lokal Olarak Başlatmak:
```bash
python Projeler/Kisisel_Sekreter_Bot/sekreter_bot.py
```

### Arka Planda Sürekli Çalıştırmak (Windows PowerShell):
```powershell
Start-Process -NoNewWindow python "Projeler\Kisisel_Sekreter_Bot\sekreter_bot.py"
```

### Buluta (Railway) Yüklemek:
Repoda halihazırda bağlı olan Railway token'ı ile tek tıkla canlıya alınıp 7/24 bilgisayar kapalıyken bile çalışabilir.
